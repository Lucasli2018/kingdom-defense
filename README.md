# 王国守卫 · 塔防（Kingdom Defense）

一款单文件 HTML5 Canvas 塔防游戏，卡通奇幻风格。零依赖、零后端，双击即玩。

## 玩法

防守你的城堡，击退怪物进攻。建造与升级 5 种塔，善用金币经济、塔搭配与减速控制，撑过所有波次。击杀敌人积累**能量**，满 100 可释放**全屏冰冻**技能扭转战局。

游戏提供三种模式、三档难度，并内置存档、成就、排行榜与新手引导，沉淀你的每一次防守成果。

## 游戏模式

| 模式 | 说明 |
|------|------|
| 🏰 战役模式 | 经典 14 波线性关卡，守住城堡即通关 |
| ∞ 无尽模式 | 第 14 波后程序化续波，敌人规模随波数递增，挑战你的最高波数 |
| 📅 每日挑战 | 基于当天日期种子生成固定波次，全员公平，冲击当日排行榜 |

> 进入游戏前在主菜单选择模式与难度；本次成绩会记录到本地排行榜。

## 难度

主菜单可在「简单 / 普通 / 困难」三档间切换，影响敌人的 **血量 / 伤害 / 金币奖励 / 移动速度**倍率，并自动记忆你的偏好：

| 难度 | 血量 | 伤害 | 金币 | 速度 |
|------|------|------|------|------|
| 简单 | ×0.8 | ×0.7 | ×1.2 | ×0.92 |
| 普通 | ×1.0 | ×1.0 | ×1.0 | ×1.0 |
| 困难 | ×1.35 | ×1.3 | ×0.9 | ×1.12 |

## 塔种

| 键 | 塔 | 成本 | 特性 |
|----|------|-----|------|
| 1 | 弩箭塔 | 70 | 快速单体，可对空 |
| 2 | 秘法塔 | 120 | 魔法溅射，可对空 |
| 3 | 投石塔 | 155 | 重炮高伤 + 溅射，无法对空 |
| 4 | 冰霜塔 | 95 | 减速冰冻，可对空 |
| 5 | 闪电塔 | 130 | 连锁闪电，自动弹射附近最多 3 个敌人（伤害递减），可对空 |

每塔可升级 3 级，逐级提升伤害 / 射程 / 射速。

## 敌人

- **哥布林**：低血高速
- **兽人**：中血带护甲
- **巨魔**：高血厚甲
- **蝙蝠**：飞行单位（仅对空塔可击中）
- **BOSS**：第 10、14 波出现，6 倍血、扣 5 命中；**血量过半进入「狂暴」状态**——加速 30% 并召唤 2 只哥布林援军，需及时集火

## 操作

- `1-5`：选择塔类型
- `左键`：在草地上放置塔 / 点中已建塔打开升级面板
- `空格`：开始 / 下一波（暂停时按空格恢复）
- `P` 或 `⏸`：暂停 / 继续
- `U`：升级选中的塔
- `S`：出售选中的塔（70% 回收）
- `Q`：释放全屏冰冻技能（能量满 100 时可用，冻结全体敌人 3 秒）
- `Esc` / 右键：取消选择
- `🔊`：静音切换

**主菜单**：选难度 → 选模式（战役 / 无尽 / 每日）→「🏆 成就」「❓ 玩法」「📊 排行」随时查看。

## 能量与技能

- 每次击杀积累能量（普通 +3，BOSS +24，上限 100）
- 能量满后，按 `Q` 或点击底部「❄ 全屏冰冻」按钮释放：所有敌人被冻结 3 秒（移动速度降至 5%），是应对密集波次与 BOSS 狂暴的关键手段

## 成就

达成后自动解锁并永久保存（主菜单「🏆 成就」查看）：

| 成就 | 条件 |
|------|------|
| 🏆 初战告捷 | 通关一次战役模式 |
| ♾ 无尽守卫 | 无尽模式到达 25 波 |
| ⚔ 屠戮勇士 | 单局击杀 50 个敌人 |
| 🏰 建筑大师 | 单局建造 10 座塔 |
| 🛡 固若金汤 | 通关时城堡毫发无伤 |
| 🌟 全兵种 | 同时拥有全部 5 种塔 |

## 新手引导

首次进入会自动弹出分步教程（选塔 → 建造 → 开波 → 升级/出售 → 技能 → 目标）。引导进度会持久化，之后不再自动弹出；任何时候都可通过主菜单「❓ 玩法」重看。

## 存档与排行榜

- **存档**：通过 `localStorage` 永久保存最高波次、最高分、已解锁成就、难度偏好与引导完成状态。换设备需用同一浏览器 / 同一域名。
- **排行榜**：每局结束将成绩（分数 / 模式 / 波数 / 日期）存入本地 Top10，主菜单「📊 排行」可随时查看。

## 运行

直接双击 `index.html` 在浏览器打开即可。

若个别浏览器对本地 Canvas `getImageData` 有限制，可启动自带静态服务器：

```bash
node server.js
# 访问 http://127.0.0.1:8765
```

## 资源

- `webp/`：游戏精灵与背景（WebP 透明格式，已优化体积）
  - 4 个塔精灵（弩箭 / 秘法 / 投石 / 冰霜）、4 个敌人精灵、1 张草地背景
  - 闪电塔为程序绘制（⚡ 符号 + 发光圆底），无独立精灵文件
- 静态背景层（草地 + 路径 + 装饰 + 城堡）在加载完成后烘焙到离屏 canvas，每帧只贴图一次，避免闪烁并提升性能
- 音效由 WebAudio API 合成，无外部音频文件

## 技术要点

- **离屏 canvas 静态层缓存**：草地 / 路径 / 装饰 / 城堡在启动时一次性绘制到离屏 canvas，每帧 `drawImage` 一次，消除每帧重绘鹅卵石等耗 CPU 元素造成的闪烁
- **首帧 dt 修正**：`last` 初始为 0，首帧直接同步为 `ts`，避免首帧巨大 dt 导致角色瞬移
- **暂停时间一致性**：暂停时 `update()` 与波次倒计时均不递减，恢复后游戏状态连续
- **连锁闪电特效**：闪电塔命中后从主目标向最近敌人逐跳弹射，渲染为带随机抖动的发光折线，伤害按 `chainFalloff` 递减
- **能量与全屏冰冻技能**：能量随击杀累积，`castFreeze()` 触发全局 `freezeAllT` 计时，敌人移动在冻结期内降至 5%
- **多阶段 BOSS**：Boss 血量过半切换 `phase2`，加速并召唤援军，绘制增加红色狂暴描边
- **WebP alpha**：所有精灵为带 alpha 通道的 WebP，无需色键去白底，体积较原 JPG 减小约 80%
- **WebAudio 合成音效**：射击 / 命中 / 建造 / 死亡 / 波次 / 胜负全程程序合成，无音频资源依赖
- **多模式与程序化波次**：无尽模式超出预设波次后按波数递增规模生成，每日挑战用日期 FNV 哈希 + LCG 生成确定性波次，保证公平性
- **localStorage 持久化**：最高记录、成就、难度偏好与引导状态本地保存；排行榜以 Top10 数组落盘，零后端
